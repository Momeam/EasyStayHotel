  • Constructor Injection (บรรทัด 13-18): รับ EasystaydbContext เข้ามาเพื่อใช้คิวรีฐานข้อมูล MySQL ผ่าน Entity Framework Core
  • Action `Index()` (บรรทัด 20-86):
    • ใช้ LINQ _context.Roomtypes.Include(rt => rt.Rooms).OrderBy(rt => rt.BasePrice).ToList(); ดึงประเภทห้องพร้อมตารางลูก rooms เพื่อนำไปนับจำนวนห้องว่างของแต่ละสาขา (กรุงเทพฯ, ชลบุรี, ภูเก็ต)
    • มีกลไก Fallback Mock Data ในกรณีที่ฐานข้อมูลยังว่างเปล่า ระบบจะสร้างข้อมูลจำลองมาตรฐาน 3 ประเภทขึ้นมาเพื่อไม่ให้หน้าเว็บล่ม
  • Action `Privacy()` & `Error()` (บรรทัด 88-97): แสดงหน้านโยบาย และจัดการ Error Id โดยปิดการแคชด้วย [ResponseCache(Duration = 0, Location = ResponseCacheLocation.None, NoStore = true)]

432 บรรทัด

หน้าที่หลัก: จัดการการยืนยันตัวตนสมาชิก: เข้าสู่ระบบ, ส่งรหัส OTP ทางอีเมล, สมัครสมาชิก, จัดการโปรไฟล์, รีเซ็ตรหัสผ่าน, และออกจากระบบ

  • `Login` (GET / POST - บรรทัด 23-98):
    • เช็ค Session เดิม ถ้าล็อกอินอยู่แล้วให้ส่งเข้าหน้าแรกทันที

    • สุ่มรหัสตัวเลข 6 หลัก Random.Shared.Next(100000, 999999) บันทึกลง Session พร้อมอายุ 5 นาที AddMinutes(5)
    • เรียกใช้ _emailService.SendOtpEmailAsync(...) ส่งอีเมลยืนยันตัวตนหาผู้ใช้จริง
  • `Register` (POST - บรรทัด 151-220):
    • ตรวจสอบความถูกต้องของรหัส OTP และเช็คว่าไม่หมดอายุ
    • บันทึกบัญชีใหม่ลงตาราง users ด้วย Role = "Customer" แล้วล้าง Session OTP เพื่อความปลอดภัย
  • `Profile` (GET / POST - บรรทัด 222-316): อ่านและอัปเดตข้อมูลผู้ใช้ พร้อมตรวจสอบรหัสผ่านเดิมก่อนอนุญาตให้ตั้งรหัสผ่านใหม่
  • `ForgotPassword` & `ResetPassword` (บรรทัด 318-423): ส่งรหัส OTP ไปที่อีเมลเดิมเพื่อรีเซ็ตรหัสผ่าน
  • `Logout` (บรรทัด 425-430): สั่ง HttpContext.Session.Clear(); เพื่อล้างเซสชันทั้งหมด คืนความปลอดภัย

  • `CalculateDiscount` (POST AJAX - บรรทัด 220-271):

    • คำนวณส่วนลด 5 รูปแบบ (Early Bird, Long Stay, Birthday Month, Group Stay 15%, Weekday Stay 5%) ผ่าน PromotionService และคืนค่าเป็น JSON อัปเดตราคาบนหน้าจอทันทีโดยไม่ต้องรีโหลดหน้าเว็บ
  • `ConfirmBooking` (POST - บรรทัด 273-488):
    • Multi-Room Booking: รวบรวมจำนวนห้องที่ลูกค้าเลือกทั้งหมด ค้นหาห้องว่างจริงในสาขานั้นมาล็อกไว้
    • อัปโหลดรูปสลิปไปที่ wwwroot/uploads/slips/ โดยตั้งชื่อด้วย Guid.NewGuid() ป้องกันชื่อไฟล์ซ้ำ
    • สร้างข้อมูลลงตาราง bookings (สถานะ Pending) และตาราง payments พร้อมปรับสถานะห้องพักในตาราง rooms เป็น `Reserved` ทันที
    • ส่งอีเมลยืนยันการจองพร้อมลิงก์ Booking Voucher ให้ลูกค้าอัตโนมัติ
  • `BookingVoucher` (บรรทัด 512-563): แสดงเอกสารยืนยันการจองขนาด A4 สำหรับพิมพ์หรือเซฟเป็น PDF รองรับการแจกแจงรายการทุกห้องที่จองในครั้งเดียว
  • `RequestRefund` (บรรทัด 620-698): ตรวจสอบเงื่อนไขการขอคืนเงิน (ต้องไม่เกิน 7 วันหลังจองและยังไม่เช็คอิน) บันทึกลงระบบ และส่งแจ้งเตือนเข้ากระดานฝ่ายบัญชี

บรรทัดคำสั่งที่อาจารย์ชี้ คำตอบแบบมืออาชีพ ทำไมต้องเขียนแบบนี้ (เหตุผลสำคัญ)
private readonly EasystaydbContext _context; การทำ Dependency Injection (DI) ให้ ASP.NET Core จัดการ Lifecycle ของ Connection ฐานข้อมูลแทนการ new เอง ช่วยประหยัด Memory และป้องกันการเชื่อมต่อค้างใน MySQL ครับ
.Include(r => r.RoomType) การทำ Eager Loading ใน EF Core สั่งให้เขียน SQL JOIN ดึงตารางลูกมาพร้อมกันในคิวรีเดียว ถ้าไม่มีบรรทัดนี้ ตอนหน้าเว็บเรียก r.RoomType.TypeName จะแครชด้วย NullReferenceException ครับ
[ValidateAntiForgeryToken] ระบบความปลอดภัยป้องกัน CSRF ตรวจสอบว่าฟอร์มที่ส่งมา มาจากหน้าเว็บของเราจริง ไม่ได้ถูกสคริปต์จากเว็บแฮกเกอร์หลอกยิงข้ามเว็บเข้ามาครับ
[HttpPost] การระบุ HTTP Method Constraint รับเฉพาะคำขอแบบ POST (Submit Form) ป้องกันไม่ให้มีคนพิมพ์ URL ส่งค่าผ่าน Address Bar (GET) ตรงๆ ครับ
[FromBody] PromoRequestData data การทำ JSON Model Binding สั่งให้ ASP.NET Core แปลงข้อมูล JSON Body ที่ส่งมาจากคำขอ AJAX ของ JavaScript ให้เป็น C# Object อัตโนมัติครับ
DateHelper.NormalizeToGregorian(...) การปรับเทียบปี พ.ศ. เป็น ค.ศ. สากล ป้องกันบั๊กปี พ.ศ. คลาดเคลื่อน (เช่น พ.ศ. 2569 แปลงเป็น ค.ศ. อาจกระโดดไป 3112) ทำให้การบันทึกและคิวรีใน MySQL ถูกต้อง 100% ครับ
HttpContext.Session.SetInt32(...) การบันทึก Server-Side Session เก็บข้อมูลระบุตัวตนของผู้ใช้ (UserId/Role) ไว้บนเซิร์ฟเวอร์ เพื่อตรวจสอบว่าผู้ใช้ล็อกอินอยู่ตลอดเวลาที่เปิดใช้งานเว็บครับ
if (!ModelState.IsValid) return View(model); การทำ Server-Side Validation ตรวจสอบ Data Annotations (เช่น [Required], [EmailAddress]) หากกรอกไม่ครบจะไม่ทำงานต่อและส่งข้อความเตือนกลับไปที่หน้าจอทันทีครับ
return RedirectToAction(...) การทำ Post-Redirect-Get (PRG) ส่ง HTTP Status 302 ให้เบราว์เซอร์วิ่งไปเปิดหน้าใหม่ ป้องกันปัญหาผู้ใช้กด F5 แล้วฟอร์มส่งซ้ำ (Duplicate Submission) ครับ
Guid.NewGuid().ToString() + "_" + fileName การสร้างชื่อไฟล์ที่ไม่ซ้ำกัน ป้องกันปัญหาชื่อไฟล์สลิปซ้ำกันเมื่อมีลูกค้าหลายคนอัปโหลดไฟล์ชื่อเดียวกัน เช่น slip.jpg ไม่ให้ไปเซฟทับไฟล์ของลูกค้าคนอื่นครับ
